## Current project

**Insurance Coverage Type and Socioeconomic Disparities in GLP-1 Receptor Agonist Use** *(manuscript in preparation)*

- **Question:** does insurance coverage type (Private, Medicare, Medicaid, Dual-eligible, uninsured) explain socioeconomic differences in GLP-1 receptor agonist use among U.S. adults with type 2 diabetes?
- **Data:** Medical Expenditure Panel Survey (MEPS), 2020-2023, pooled across four years.
- **Methods:** a reproducible R pipeline that applies one set of variable definitions to every survey year; design-based survey analysis with 128 balanced repeated replication (BRR) weights; KHB and counterfactual mediation, both implemented by hand so they accept replicate weights; interaction tests, E-values, and sensitivity analyses.

The repository is private until publication. **Analysis code is available to hiring teams on request.**
